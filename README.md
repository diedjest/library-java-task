# JavaTask1Library

Консольное приложение для учёта книг домашней библиотеки. Данные хранятся в PostgreSQL, схема создаётся миграциями Liquibase при запуске.

## Возможности

- показать все книги (сортировка по фамилии автора)
- добавить, отредактировать и удалить книгу
- поиск по автору и по ISBN
- добавить жанр книге (не больше 3)
- выдать книгу читателю и принять обратно

Правила: ISBN-10 или ISBN-13 и уникален в каталоге; выданную книгу удалить нельзя.

## Запуск в Docker

```
docker compose run --rm app
```

Команда поднимает PostgreSQL, ждёт его готовности, применяет миграции и открывает консольное меню. Данные хранятся в томе `library-data` и сохраняются между запусками. Полностью сбросить базу: `docker compose down -v`.

При первом запуске миграции добавляют четыре демонстрационные книги (`003-seed-demo-books`).

## Запуск без Docker

1. Поднять только базу: `docker compose up -d db` (наружу она опубликована на порту 5433, чтобы не конфликтовать с локальным PostgreSQL)
2. Запустить `ru.vsu.cs.uvarovdp.Main` из IDE или `mvn package` и `java -jar target/JavaTask1Library-1.0-SNAPSHOT.jar`

Для базы из compose укажите `DB_URL=jdbc:postgresql://localhost:5433/library`. Параметры подключения берутся из переменных окружения; без них используются значения по умолчанию:

| Переменная | По умолчанию |
|---|---|
| `DB_URL` | `jdbc:postgresql://localhost:5432/library` |
| `DB_USER` | `library` |
| `DB_PASSWORD` | `library` |

## База данных

Миграции лежат в `src/main/resources/db/changelog`, главный файл — `db.changelog-master.yaml`.

| Таблица | Назначение |
|---|---|
| `books` | книги: ISBN уникален, статус `AVAILABLE`/`BORROWED`, читатель обязателен только для выданной книги |
| `book_genres` | жанры книги с порядковым номером, удаляются вместе с книгой |

Новая миграция - новый файл в `changes/` и строка `include` в мастер-файле. Применённые changeset'ы менять нельзя.

## Структура

| Пакет | Назначение |
|---|---|
| `entity` | `Book`, `BookStatus`, базовая `AbstractEntity` |
| `dto` | `BookData` — данные книги для сервиса |
| `validator` | проверка данных книги |
| `repository` | интерфейсы, `JdbcBookRepository` и `InMemoryBookRepository` |
| `config`, `db` | настройки подключения, `DataSource` и запуск миграций |
| `service` | бизнес-логика (`LibraryService`) |
| `ui` | консольное меню и команды |
| `factory` | сборка сервиса и UI |
| `ex`, `util`, `domain` | исключения, утилиты, константы |

## Тесты

```
mvn test
```

JUnit 5 и Mockito. Сервис и консольный UI тестируются на моках зависимостей. `JdbcBookRepository` и миграции проверяются на настоящем PostgreSQL через Testcontainers, поэтому для этих тестов нужен запущенный Docker (без него они пропускаются).
